# Lost and Found Portal

A web-based Lost and Found Portal developed using Flask and SQLite.

## Features

- User Registration and Login
- Report Lost Items
- Report Found Items
- Search Items
- Manage Item Records
- Responsive User Interface

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

```bash

venv\Scripts\activate

pip install -r requirements.txt

python app.py
```
